# Q&A to HTML Converter

This project converts a text-based Q&A file into an HTML document, displaying questions with their corresponding answers, and preserving code formatting (using tabs or spaces) for any code blocks in the answers.

## Features:
- Converts a `.txt` file with questions and answers into a neatly formatted HTML page.
- Supports code blocks in answers by detecting lines starting with three tabs (`\t\t\t`).
- Inline CSS is used to preserve the exact indentation of code blocks.
- Questions are displayed with their respective answers, formatted with proper HTML tags.

## Files:
- `generate_html.py`: Python script to convert the Q&A text file into an HTML file. This script also contains the styling.
- `questions.txt`: The input text file containing questions and answers (should be structured in a specific way, see the example below).
- `index.html`: The output HTML file generated by the Python script.

## How It Works:
1. The script reads the `qa.txt` file, processes the questions and answers.
2. It detects code blocks by looking for lines that start with exactly three tabs (`\t\t\t`).
3. It generates an HTML file (`index.html`) where questions are displayed in `<h3>` tags, answers in `<p>` tags, and code blocks are wrapped in `<pre><code>` tags.
4. Inline CSS ensures that the code blocks maintain their original indentation and formatting.

## How to Use:

### 1. Prepare the Input File
Create a `questions.txt` file with the following structure:


- **Questions** should be written on their own line.
- **Answers** should follow the question.
- **Code blocks** should be indented by three tabs.

### 2. Run the Python Script
Make sure you have Python installed. Run the script using the command:

	python generate_html.py
